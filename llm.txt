# Bintana

> The runtime: a declarative UI language and an application runtime in C and
> QuickJS. This index is for working *on* the runtime and the IDE. The
> documentation for writing an application is in the two repositories below.

## Start here

- [AGENTS.md](AGENTS.md): the guide for working on the repository -- commands, conventions, the rules every change follows, and an index of the rest
- [docs/agents/](docs/agents/): the traps of each area with their evidence -- what a change to that area has to know
- [docs/notes/](docs/notes/): design narratives -- why a feature is the way it is, and what was measured on the way
- [docs/architecture.md](docs/architecture.md): boot sequence, the C/JS split, the class table, event dispatch, the object model, lifetimes

## Extending and building

- [docs/extending.md](docs/extending.md): adding a widget, a property, an enum, an event
- [docs/plugins.md](docs/plugins.md): the native plugin table and its loader
- [docs/installing.md](docs/installing.md): dependencies per distribution, install, packaging
- [docs/testing.md](docs/testing.md): the projects, what they prove, and what is checked by hand
- [docs/ide-internals.md](docs/ide-internals.md): how the IDE is built -- its parsers, its caches, the shape of its tree
- [docs/plans/README.md](docs/plans/README.md): designs argued before they are code
- [docs/issues/README.md](docs/issues/README.md): reported gaps, and the form to report one
- [docs/llm/issues.md](docs/llm/issues.md): the language's decisions, and what is deliberately not here

## The contract

- [api.json](api.json): the public surface as data -- generated by `./tools/apijson.sh` and held to the C by `./tests/api.sh`
- [llms-full.txt](llms-full.txt): the documents above, concatenated, for one fetch

## Documentation for application authors

- [bintana-docs](https://github.com/getbintana/bintana-docs): the reference and the compact contract, what the IDE's F1 reads
- [bintana-llm](https://github.com/getbintana/bintana-llm): writing an application with no IDE
